# CutTag Pipeline

## Inputs
- `config.yml` — configuration (generally under dataset root)
- `samplesheet.csv` — sample metadata and FASTQ paths (under dataset root, can be generated by running script at first time)
- Raw FASTQ files (paths defined in the samplesheet.csv)

## Example usage
```
script_dir=/mnt/c/Users/haohe/GitHub/myScript/NGS/CutTag
dataset_dir=/mnt/d/2026-01-01_CutTag_dataset

# Enter dataset directory
cd $dataset_dir

# Run to generate samplesheet.csv
bash $script_dir/run_cuttag.sh config.yml

# Edit samplesheet.csv
# Edit config.yml

# Re-run pipeline
bash $script_dir/run_cuttag.sh config.yml
```

## Outputs
- QC reports and trimmed FASTQs
- Aligned BAMs and peak files (BED/PEAK)
- Normalized count tables and summary plots
- Logs

## Notes
- For complicated genomic setting, refer to `helper.sh`
- For SpikeFree method, refer to`spike_free_normalization.R`.
- For custom bed region, please edit `config.yml`

## Heatmap options (config.yml)
- `heatmap_binsize` (default `50`) — bp per bin for `computeMatrix`. Larger values reduce memory and runtime for big BED files: memory ≈ n_regions × n_samples × (window/binsize) × 8 bytes. 100k regions × 30 samples × 120 bins ≈ 3 GB at binSize 50.
- `heatmap_max_regions` (default `100000`) — BED files with more regions (e.g. consensus peaks from many samples) are deterministically subsampled (fixed random source) to bound matrix size. Subsampled BED is cached in the corresponding heatmap output directory (e.g. `result/multiqc/` for global QC, `04_peaks/<tool>/` for peak QC).
- All samples stay in a single matrix (one row per BED region, samples side-by-side), so groups remain directly comparable in one heatmap.

## PCA (config.yml)
- PCA is generated by `scripts/plot_pca.py` (replaces deepTools `plotPCA`, whose `--log2` flag is broken in v3.5.6 and whose zero-lines squeeze the data cloud).
- `pca_ntop` (default `100000`) — top-N most-variable 10 kb bins used for the PCA (0 = all bins).
- Outputs: `BigWig_*_PCA.pdf` (PC1 vs PC2, colored by the samplesheet `group` column with categorical palette, scree panel, adaptive axes) and `BigWig_*_PCA.tab` (per-sample loadings + eigenvalues, same format as `plotPCA --outFileNameData`).

## S/N ratio from heatmap matrix
`func/heatmap_snr.R` (run in RStudio): reads a saved `*_mat.gz`, computes
per-sample signal-to-noise (center ± `center_width` bp / outermost `flank_width` bp)
and writes `heatmap_snr_summary.csv`, `heatmap_snr_per_region.csv`, and a boxplot.
Set `mat_file`/`out_dir`/widths in the config section at the top of the script.
