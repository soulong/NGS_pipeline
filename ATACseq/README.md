# ATACseq Pipeline

Assay for Transposase-Accessible Chromatin using sequencing (ATAC-seq) analysis pipeline.

## Overview

This pipeline processes ATACseq data from raw FASTQ files to peak calls and QC metrics. It is designed to be parallel to the CutTag pipeline, sharing common helper functions while accounting for ATACseq-specific requirements:

- **Tn5 transposase offset correction** (--shift -100, --extsize 200)
- **Mitochondrial read filtering** (often 20-80% of ATACseq reads)
- **Nucleosome positioning analysis** (fragment length distribution)
- **Open chromatin peak calling** (narrow peaks)

## Inputs

- `config.yml` — configuration (generally under dataset root)
- `samplesheet.csv` — sample metadata and FASTQ paths (under dataset root, can be generated by running script at first time)
- Raw FASTQ files (paths defined in the samplesheet.csv)

## Example usage

```bash
script_dir=/path/to/NGS_pipeline/ATACseq
dataset_dir=/path/to/your/ATACseq_project

# Enter dataset directory
cd $dataset_dir

# Run to generate samplesheet.csv
bash $script_dir/run_atacseq.sh config.yml

# Edit samplesheet.csv (fill in sample metadata)
# Edit config.yml (adjust parameters as needed)

# Re-run pipeline
bash $script_dir/run_atacseq.sh config.yml
```

## Configuration

### Key ATACseq-specific parameters

| Parameter | Default | Description |
|-----------|---------|-------------|
| `max_frag_length` | 2000 | Max fragment length (captures nucleosome-free + mono/di/tri-nucleosomes) |
| `macs_parameter` | `--nomodel --shift -100 --extsize 200 -q 0.05` | Tn5 offset correction |
| `remove_mito` | true | Remove mitochondrial reads from analysis |
| `norm_method` | CPM | Normalization method |

### Tn5 Transposase Offset

ATACseq uses Tn5 transposase which creates a 9-bp duplication at insertion sites. The parameters `--shift -100 --extsize 200` correct for this by:
- Shifting reads by -100 bp (center of Tn5 insertion)
- Extending to 200 bp (estimated fragment size)

## QC Metrics

### Fragment Length Distribution

ATACseq shows characteristic nucleosome positioning:
- **< 100 bp**: Nucleosome-free regions (NFR) - open chromatin
- **~180-200 bp**: Mononucleosome
- **~360-400 bp**: Dinucleosome
- **~540-600 bp**: Trinucleosome

### FRiP Score

Fraction of Reads in Peaks - measures enrichment:
- **Good**: > 20-30%
- **Acceptable**: > 10%
- **Poor**: < 5%

### Mitochondrial Content

High mitochondrial reads indicate poor nuclei quality:
- **Good**: < 20%
- **Acceptable**: 20-50%
- **Poor**: > 50%

## Notes

- This pipeline shares helper functions with CutTag (`../helper.sh`)
- Parent directory scripts (`helper.sh`, `ngs_helper.R`) are read-only
- For spike-in normalization (not typical for ATACseq), refer to CutTag pipeline
- Custom BED regions can be added in `config.yml` for targeted QC

## Dependencies

- `fastp` - Adapter trimming
- `bowtie2` - Alignment
- `sambamba` / `samtools` - BAM processing
- `macs3` - Peak calling
- `deeptools` - Signal visualization and QC
- `bedtools` - Genomic interval operations
- `multiqc` - QC report aggregation
